
# Week7 ユーザー登録・ログイン機能 仕様書

## 1. 目的

ユーザー登録・ログイン・ログアウト機能を実装する。

ログインしたユーザーが自分の時間割を利用できるようにする。

## 2. 対象画面（URLとHTTPメソッド）

| HTTPメソッド | URL | 処理内容 |
|---|---|---|
| GET | /register | ユーザー登録画面を表示する |
| POST | /register | ユーザー登録を行う |
| GET | /login | ログイン画面を表示する |
| POST | /login | ログイン処理を行う |
| POST | /logout | ログアウト処理を行う |
| GET | /entries | ログイン中のユーザーの時間割画面を表示する |

## 3. ユーザー登録機能

### 入力項目

- 名前
- メールアドレス
- パスワード
- パスワード確認用

### バリデーション

- 名前は必須とする
- メールアドレスは必須とする
- メールアドレスは正しい形式で入力する
- 登録済みのメールアドレスは使用できない
- パスワードは8文字以上とする
- パスワードと確認用パスワードは一致させる

### エラーメッセージ

- 名前が未入力：「名前を入力してください」
- メールアドレスが未入力：「メールアドレスを入力してください」
- メールアドレスの形式が不正：「メールアドレスの形式で入力してください」
- メールアドレスが登録済み：「このメールアドレスはすでに登録されています」
- パスワードが8文字未満：「パスワードは8文字以上で入力してください」
- 確認用パスワードが一致しない：「パスワードが確認用と一致しません」

### 登録成功時の動作

- usersテーブルにユーザー情報を保存する
- パスワードはハッシュ化して保存する
- 登録したユーザーを自動ログインさせる
- /entries にリダイレクトする

### 登録失敗時の動作

- 登録画面にエラーメッセージを表示する
- 入力済みの名前とメールアドレスは保持する
- パスワードは再表示しない

## 4. ログイン機能

### 入力項目

- メールアドレス
- パスワード

### ログイン成功時の動作

- 入力された情報で認証する
- ログイン状態を保存する
- セッションIDを再生成する
- /entries にリダイレクトする

### ログイン失敗時の動作

- ログイン画面に戻る
- 「メールアドレスかパスワードが違います」と表示する
- 入力済みのメールアドレスは保持する
- パスワードは保持しない

## 5. ログアウト機能

- POST /logout でログアウトする
- ログイン状態を終了する
- セッションを無効化する
- CSRFトークンを再生成する
- /login にリダイレクトする

## 6. 未ログイン時のアクセス制御

- /entries はログイン済みユーザーだけがアクセスできる
- 時間割登録・削除などの保護対象ルートにも認証を適用する
- /courses もログイン済みユーザーだけがアクセスできる
- 未ログイン状態で保護対象ルートにアクセスした場合は /login にリダイレクトする
- Laravelのauthミドルウェアを使用する

## 7. 時間割画面

- ログイン成功後は /entries を表示する
- 画面の見出しは「〇〇さんの時間割」とする
- 〇〇にはログイン中のユーザー名を表示する
- ログアウトボタンを設置する
- ログアウトボタンはPOST /logoutで送信する

## 8. 受け入れテスト用チェックリスト

### 8-1. ユーザー登録

- [ ] /register を開く → ユーザー登録画面が表示される

- [ ] 名前を空欄にして登録する → 「名前を入力してください」と表示される
- [ ] メールアドレスを空欄にして登録する → 「メールアドレスを入力してください」と表示される
- [ ] メールアドレスに「abc」を入力して登録する → 「メールアドレスの形式で入力してください」と表示される
- [ ] 登録済みのメールアドレスで登録する → 「このメールアドレスはすでに登録されています」と表示される
- [ ] パスワードを7文字で登録する → 「パスワードは8文字以上で入力してください」と表示される
- [ ] パスワードと確認用パスワードを違う内容にする → 「パスワードが確認用と一致しません」と表示される

### 8-2. ログイン

- [ ] /login を開く → ログイン画面が表示される
- [ ] 正しいメールアドレスとパスワードを入力する → /entries に移動する
- [ ] 間違ったパスワードを入力する → 「メールアドレスかパスワードが違います」と表示される
- [ ] ログインに失敗する → 入力したメールアドレスが残っている

### 8-3. ログアウト

- [ ] ログアウトボタンを押す → /login に移動する

### 8-4. 未ログイン時のアクセス

- [ ] ログインせずに /entries を開く → /login に移動する
- [ ] ログインせずに /courses を開く → /login に移動する
- [ ] ログイン後に /entries を開く → 時間割画面が表示される

### 8-5. データベースの確認

- [ ] 新しいユーザーを登録する → usersテーブルにユーザーが追加される
- [ ] 登録したユーザーのpasswordを確認する → 入力したパスワードがそのまま保存されていない
